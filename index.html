How Radix Sort Works

Radix sort processes numbers digit by digit, using counting sort as a subroutine

LSD Radix Sort

Least Significant Digit

Processes digits starting from the rightmost (least significant) digit to the leftmost. Uses a stable counting sort at each step.

1 Start from the ones digit (rightmost)
2 Sort all elements by current digit using counting sort
3 Move to the next significant digit (tens, hundreds...)
4 Repeat until most significant digit is processed
💡 Best for fixed-length integers and strings. Always processes all digits.

MSD Radix Sort

Most Significant Digit

Processes digits starting from the leftmost (most significant) digit. Recursively sorts sub-groups created at each step.

1 Start from the highest-order digit (leftmost)
2 Distribute elements into buckets (0-9) based on current digit
3 Recursively sort each non-empty bucket on the next digit
4 Concatenate all buckets to get sorted result
💡 Can short-circuit early. Better for variable-length data and lexicographic sorting.

LSD vs MSD Comparison

Feature LSD Radix Sort MSD Radix Sort
Direction Right → Left (ones first) Left → Right (highest first)
Approach Iterative Recursive
Stability Stable Needs extra care
Best For Fixed-length keys Variable-length keys
Early Termination No Yes (can skip)
Memory O(n + k) O(n + k) per recursion level
Use Case Integers, phone numbers Strings, lexicographic sort
