Radix Sort Visualizer
  🚀 Introduction & Overview
  
  An interactive and educational Radix Sort Visualizer built to demonstrate how the radix sort algorithm works step by step. This project visually explains how numbers are sorted digit by digit, making it easier to understand a concept that can otherwise feel abstract.
  
  Radix Sort is a non-comparative sorting algorithm that processes numbers based on individual digits (ones, tens, hundreds, etc.). This visualizer breaks down each pass of the algorithm and shows how elements are grouped and rearranged in real time.
  
  This project is especially useful for:
  
  Students learning sorting algorithms
  Beginners exploring algorithm visualization
  Developers who want a deeper understanding of Radix Sort
  
✨ Features

    ✅ Step-by-step visualization of Radix Sort
    📊 Clear representation of digit-wise sorting
    🎯 Easy-to-understand UI
    ⚡ Real-time updates during sorting
    🔁 Multiple passes (ones, tens, hundreds, etc.)
    🎨 Clean and interactive design

⚙️ How It Works
    The user inputs or generates an array of numbers
    The algorithm processes numbers digit by digit
    Numbers are grouped based on the current digit (0–9)
    The list is reconstructed after each pass
    The process repeats until all digits are processed
